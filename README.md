# Multi-Agent AI Interview Platform

An AI-powered interview platform that simulates technical interviews using multiple AI agents. The platform evaluates candidate responses, manages interview workflows, and provides real-time feedback.

## Features
- AI-powered technical interviews
- Multi-agent interview workflow using LangGraph
- Real-time candidate evaluation
- Secure user authentication
- Scalable microservices architecture
- Redis-based caching and session management

## Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB
- Redis
- LangChain
- LangGraph
- Docker
- Microservices
- Firebase Authentication
- AWS

## Project Structure
```
frontend/   # React application
backend/    # Node.js & Express APIs
```

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/manojsj13/Multi-Agent-AI-Interview-platform.git
```

2. Install dependencies:
```bash
cd frontend
npm install

cd ../backend
npm install
```

3. Start the application:
```bash
npm run dev
```
